ЛАБОРАТОРНА РОБОТА №2: Консольні утиліти кібербезпеки
Варіант 6: Аудитор надійності та масок словників паролів

1. ЗАГАЛЬНИЙ ОПИС

---

- Завдання 1 (task1.py): Модель користувача, системи безпечних сесій,
  аутентифікації на основі PBKDF2-HMAC та журналювання подій на основі ООП.
- Завдання 2 (task2.py): Консольна утиліта для аудиту якісного складу
  словників паролів із використанням генераторів, регулярних виразів та Counter.

2. ВСТАНОВЛЕННЯ ЗАЛЕЖНОСТЕЙ

---

Для перевірки стилю коду та форматування використовується лінтер Ruff.
Виконайте в терміналі з кореня репозиторію:
pip install -r requirements.txt

3. Тестові дані

---

Тестові дані для Завдання 2 будуть надані в окремому архіві lab2_data.zip . Розпакуйте каталог свого варіанта в labs/lab02/data/ .Додайте до .gitignore .venv/ та pycache/ . Працюйте лише з навчальними даними з архіву; не публікуйте реальні журнали, паролі чи ключі.

4. ПРИКЛАДИ ЗАПУСКУ КОМАНД

---

- Запуск демонстрації об'єктно-орієнтованої моделі (Завдання 1):
  python -m labs.lab02.main demo

- Запуск утиліти аудиту словника паролів (Завдання 2):
  python -m labs.lab02.task2 --wordlist labs/lab02/data/passwords.txt --min-length 8 --top-masks 5 --output-stats labs/lab02/data/mask_audit_report.json
  ,або
  python -m labs.lab02.task2 --wordlist labs/lab02/data/passwords.txt

5. ОПИС CLI АРГУМЕНТІВ (Завдання 2)

---

- --wordlist : Шлях до файлу зі словником паролів (обов'язковий параметр).
- --min-length : Мінімальна довжина для класифікації пароля як «слабкого» (за замовчуванням: 8).
- --top-masks : Кількість топових масок паролів у звіті (за замовчуванням: 5).
- --output-stats : Шлях до вихідного JSON-файлу для збереження результатів (за замовчуванням: labs/lab02/data/mask_audit_report.json).
